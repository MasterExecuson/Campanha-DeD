# Regras de Experiência (XP)

A campanha utiliza **cinco fontes de XP**. A XP é concedida ao final de cada sessão ou quando o evento qualificador ocorre, conforme indicado abaixo.

## 1. XP de Monstros

- A XP total dos monstros derrotados (ou superados) é **dividida igualmente entre os PCs presentes**.
- **Retainers e hirelings** contam como meia parte na divisão.
- PCs ausentes da sessão não recebem XP de combate.
- Derrotar não significa necessariamente matar: enganar, fugir ou neutralizar inimigos também concede XP integral.

## 2. Ouro Recuperado (Tesouro)

- **Conversão: 1 GP = 1 XP**.
- A XP só é concedida quando o ouro é **levado para um assentamento civilizado seguro** (cidade, vila, fortaleza aliada, templo, etc.).
- Ouro perdido, gasto no caminho ou roubado antes de chegar ao destino seguro **não gera XP**.
- A XP de tesouro é dado a todos os PCs de forma igual.
- Eventualmente podemos transicionar essa regra para ser um pouco mais rígida (como exigir que gastem esse ouro)

> [!note] Critério de "lugar seguro" Qualquer assentamento civilizado onde o personagem possa razoavelmente guardar, depositar ou gastar a riqueza sem risco imediato. O mesmo critério é usado para descanso.

## 3. Exploração

- Cada hex novo explorado pelo grupo concede XP, dado aos PCs presentes.
- A XP varia conforme o conteúdo descoberto:

| Tipo de descoberta                                                            | XP      |
| ----------------------------------------------------------------------------- | ------- |
| Hex vazio explorado (terreno mapeado, sem ponto de interesse)                 | 50      |
| Landmark menor (ruína pequena, marco natural curioso, acampamento abandonado) | 100–150 |
| Local significativo (assentamento oculto, santuário, masmorra menor)          | 200–300 |

- A XP é concedida quando o hex é efetivamente explorado, não apenas atravessado.
- Cada hex só concede XP **uma vez**, na primeira descoberta significativa.

## 4. Objetivos Pessoais

Cada personagem pode manter **1 a 3 objetivos pessoais ativos** entre os jogadores e o GM. Quando concluídos, concedem XP **apenas ao personagem que os perseguiu**.

|Escopo do objetivo|XP|
|---|---|
|Pequeno (curto prazo, baixo esforço, recorrente)|50|
|Médio (envolve múltiplas sessões ou risco moderado)|150|
|Grande (define o personagem, envolve grande risco ou esforço prolongado)|300|

- Os objetivos devem ser registrados na ficha ou em nota separada.
- Quando um objetivo é concluído, o jogador pode **propor novos objetivos** para substituí-lo.

> [!example] Exemplos
> 
> - **Pequeno**: Recuperar uma relíquia de família em uma única expedição.
> - **Médio**: Estabelecer uma rede de contatos comerciais em uma cidade.
> - **Grande**: Vingar a morte de um mentor; fundar uma ordem religiosa.
